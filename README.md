# localTT

A local-first tabletop companion for D&D 5e: a locally hosted web app that
digitizes the character sheet and adds light bookkeeping automation for an
in-person or voice-call party.

Backend only for now. Start with [`RFC-0001-localtt.md`](RFC-0001-localtt.md)
for intent, [`docs/architecture.md`](docs/architecture.md) for the as-built
structure, and [`AGENTS.md`](AGENTS.md) for the workflow.
